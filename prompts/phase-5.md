# Phase 5 Prompt

你是资深 Go 框架工程师、开源维护者、长期基础设施项目 owner。请对仓库 `github.com/silen/nuwa` 执行“非兼容性重构”的第 5 阶段。

参考结构风格：

https://github.com/gin-gonic/gin

## 全局背景

默认前 4 个阶段已完成：

1. 架构审计与蓝图已完成
2. 根包已瘦身
3. 基础设施包已迁移
4. 中间件、绑定、内部实现已整理

## 本阶段目标

完成收尾、格式化、测试、文档补充和最终重构报告。

## 本阶段必须完成的事项

1. 全量 `gofmt`
2. 执行 `go test ./...`
3. 修复测试失败
4. 清理无用文件
5. 清理无用 import
6. 清理无用桥接层和遗留兼容代码
7. 补充必要的 `doc.go`、README 或说明文档

## 最终报告必须包含

1. 当前架构摘要
2. 当前问题列表
3. 目标架构说明
4. 重构后的目录树
5. 关键设计决策
6. 所有破坏兼容点清单
7. 测试结果摘要
8. 尚可继续优化的项

## 最终验收标准

1. 目录结构清晰
2. 根包职责明确
3. 基础设施包边界明确
4. 无 panic 正常控流
5. 无 `tools` 大杂烩
6. 无错误命名包
7. 代码完成格式化
8. 测试通过

## 强约束

1. 不要做兼容迁移包袱
2. 不要引入新的大杂烩目录
3. 不要保留 `Controller` / `Service` / `Model`
4. 不要恢复 panic 控流
5. 不要把仓库改造成业务系统模板

## 执行要求

请直接完成收尾工作并输出完整报告，不要停留在建议层。
如果有无法在本阶段完成的问题，明确列出并说明原因。
